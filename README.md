# 💖 Charity Store - Charity Clothes Store

A complete, fully functional charity clothes store website with e-commerce functionality and admin panel. Built with pure HTML5, CSS3, and JavaScript - no external dependencies required!

![Charity Store](https://via.placeholder.com/800x400/e74c3c/ffffff?text=Charity+Store)

## 🌟 **Live Demo**

- **Public Website:** Open `index.html` in your browser
- **Admin Panel:** Navigate to `admin/login.html`
  - **Username:** `admin`
  - **Password:** `admin123`

## ✨ **Features**

### 🛍️ **Public Website**
- **Homepage** - Hero section, mission statement, featured products, testimonials
- **Shop** - Product catalog with advanced filtering, search, and pagination
- **Product Pages** - Detailed product views with shopping cart functionality
- **Shopping Cart** - Persistent cart with quantity management
- **Checkout** - Complete checkout process with payment simulation
- **About/Story** - Organization timeline, team members, values
- **Donations** - Forms for both monetary and clothing donations
- **Impact** - Success stories and community impact metrics
- **Contact** - Contact form, FAQ, and location information

### 🔧 **Admin Panel**
- **Dashboard** - Real-time analytics and key metrics
- **Product Management** - Full CRUD operations for inventory
- **Order Management** - Order tracking and status updates
- **Donation Tracking** - Manage monetary and clothing donations
- **Content Management** - Edit website content and settings
- **Data Export** - Export data to CSV for reporting

## 🚀 **Quick Start**

### **Running the Website**
1. Clone this repository
2. Open `index.html` in any modern web browser
3. No build process or server required!

### **Accessing Admin Panel**
1. Navigate to `admin/login.html`
2. Login with credentials: `admin` / `admin123`
3. Manage products, orders, and donations
