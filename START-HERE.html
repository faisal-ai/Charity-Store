📋 How to Start the Server

  1. Open Terminal in this folder
  2. Run: ./start-server.sh
  3. Or run: python3 -m http.server 8000
  4. Then refresh this page or click the links above

Note: The website requires a local server to function properly. Opening HTML files directly won't work due to browser security restrictions.
